How to open this Allure report locally
=====================================
Option A (Mac/Linux):
  1) Open terminal in this folder
  2) python3 -m http.server 8000
  3) Open http://localhost:8000

Option B (Windows PowerShell):
  1) cd to this folder
  2) python -m http.server 8000
  3) Start-Process http://localhost:8000

Note: Opening index.html with file:// may show "Loading..." due to browser security.
